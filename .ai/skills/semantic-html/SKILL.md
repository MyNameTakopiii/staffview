# Semantic HTML Guidelines

## Principles
1. **Semantic Tags**: Use `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` instead of unsemantic `<div>` soup.
2. **Heading Hierarchy**: Maintain logical `<h1>` -> `<h2>` -> `<h3>` heading structure without skipping levels.
3. **Form Elements**: Associate every `<input>`, `<select>`, and `<textarea>` with an explicit `<label>` element.
4. **Interactive Controls**: Use native `<button>` for clickable actions and `<a>` / `<Link>` for page navigation.
