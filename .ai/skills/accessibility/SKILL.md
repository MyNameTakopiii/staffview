# Web Accessibility (a11y) Guidelines

## Principles
1. **ARIA Attributes**: Provide descriptive `aria-label`, `aria-describedby`, and `aria-live` attributes for real-time status updates and dynamic UI elements.
2. **Keyboard Navigation**: Ensure all interactive form controls, buttons, and links are focusable and usable via keyboard (`Tab`, `Enter`, `Space`).
3. **Focus States**: Never disable default focus rings without providing visible high-contrast custom focus indicators.
4. **Color Contrast**: Maintain minimum WCAG AA contrast ratio (4.5:1 for normal text, 3:1 for large text).
